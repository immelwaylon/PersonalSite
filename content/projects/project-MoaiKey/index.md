## Project Overview
This project involved creating functional, aesthetic keycaps featuring Moai statues through 3D modeling and printing. By modifying existing models and optimizing for printability, I developed keycaps that maintain the iconic Moai appearance while providing secure fitment on mechanical keyboard switches.

## Design Process
### Source Materials
I integrated three existing models to create the final design:
- **[High-poly Moai model](https://www.thingiverse.com/thing:144668)** for detailed facial features
- **[Low-poly Moai model](https://www.thingiverse.com/thing:908062)** for structural simplicity
- **Standard keycap base** for mechanical compatibility

### Modeling Approach
Using TinkerCAD, I implemented several key modifications:
- **Hollowed the Moai model** to reduce material usage and printing time
- **Integrated keycap stem** precisely centered for stable keypress operation
- **Adjusted tolerances** through iterative testing to ensure snug switch fit
- **Scaled proportions** to maintain ergonomic key height while preserving visual appeal

### Iterative Refinement
The design required multiple iterations to address:
- **Fitment issues** on different switch types (Cherry MX, Kalih, etc.)
- **Structural integrity** to prevent cracking during keypresses
- **Print orientation** optimization to minimize support material
- **Surface quality** improvements for better aesthetic results

## Final Design
The [completed model](https://www.tinkercad.com/things/hOMm323wbmz-moaimoyai-head-keycap) includes multiple variations supporting different keyboard switch profiles while maintaining the distinctive Moai appearance.
